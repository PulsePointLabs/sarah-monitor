## Confirmed defects (fixed in 0.25.0)

1. **No calibration-before-logging.** Hold/contraction detection starts as soon as any rest exists; auto rest appears after ~2 s of samples, so insertion and handling pressure is counted as contractions (explains Session A's installation "strong contractions").
2. **No sensor-integrity states.** Nothing records CIVET disconnects/reconnects, rest captures, zeroing, or suspicious drops. A sensor that slips out of its probe produces a large drop below rest that nothing flags; re-seating at a different preload with a fixed captured rest leaves a permanent offset that reads as an endless "hold" (consistent with Session B's 507 s of "holding").
3. **Prolonged positive pressure is counted as a contraction.** A hold has no maximum duration, so a 4-minute offset is reported as a 4-minute contraction and feeds "Long pelvic hold" and the arousal engine.
4. **Duplicate flag labels in one CSV row.** Two flags of the same kind overlapping one second print the title twice ("Long pelvic hold | Long pelvic hold").
5. **Pre-session BP shown as contemporaneous.** BP from up to 15 min before the start is included, and the elapsed-time formatter clamps negative times to `0:00`, so an earlier reading prints as if taken at the start.
6. **Session-type carryover.** Only Masturbation/Sexual/Exploration set the response context; General/Hybrid/Kegel keep whatever the last session set (persisted across launches).
7. **CIVET events filed under the Foley.** Hands-free assigns a procedure-step note with no device word to the only device listed; the CIVET is a sensor, not a session device, so "adjusting the probe" was attached to the Foley. Claude's categorizing prompt had the same gap.
8. **No research export.** The only export is one row per second (last raw value, mean/max above rest). The native 10 Hz pressure, beat-level RR and ECG are in the database but cannot be exported.
9. **Retrospective annotation incomplete.** No source (video, recollection, observation), no timing uncertainty, no time range, and no way to type a time.

## Flagged for Ben (not changed)

- **EMG already influences the arousal engine** (adds to approach/plateau scores when an EMG device is connected and calibrated). The brief says not to activate unvalidated EMG classifiers; this one predates the brief. Left as is pending a decision.
- **RR timestamps are packet times**, not beat times (several RR intervals share one timestamp). The research export adds an estimated beat time (packet time minus the later intervals in the same packet) and labels it as an estimate.
- Displacement cannot always be told apart from a genuine large pressure change by pressure alone (the brief says the same). The detector only reacts to drops well below the relaxed rest, which pelvic muscle activity does not produce.

## Methods: established vs exploratory

- Established: NN-interval HRV (RMSSD, SDNN, pNN50) per ESC/NASPE 1996; artifact/ectopic exclusion; reporting window length and signal quality with every value.
- Adapted: ICS urodynamic practice that a sudden pressure fall signals a displaced/expelled measuring catheter → "possible sensor displacement" on a sustained drop well below rest.
- Exploratory (thresholds not yet validated on recordings): displacement drop size and persistence, negative baseline-shift detection, the 30 s boundary between a contraction and "sustained elevation", episode progression metrics.
